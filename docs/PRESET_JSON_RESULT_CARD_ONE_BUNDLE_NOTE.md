# Preset JSON result-card one-bundle note

Use this note when exported `oss-launchpad presets --json` metadata is being wired into a tiny web form that should end in one believable result card and one downloadable bundle.

## Scope rule

- One chooser or form submit.
- One visible result card.
- One downloadable proof bundle.
- No secondary dashboards before the first path feels reviewable.

## Why

This keeps the first generated `web-app` proof aligned with UI/UX-first demo work instead of widening into too many screens too early.
