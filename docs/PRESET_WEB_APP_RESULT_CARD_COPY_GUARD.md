# PRESET_WEB_APP_RESULT_CARD_COPY_GUARD

Use this note when the first `web-app` proof already has one believable form -> result-card flow and the next task is only copy polish.

## Copy guardrails

- Keep the headline outcome visible without opening a second screen.
- Keep one primary action only.
- Keep download/export wording concrete.
- Keep labels short enough to scan in one pass.

## Pass signal

A maintainer can understand the result card in one glance and knows exactly what to click next.
