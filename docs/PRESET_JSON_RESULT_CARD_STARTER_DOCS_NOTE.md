# Preset JSON result card starter docs note

Use this when the first preset chooser or setup form already shows one visible result card and you need the next maintainer action to stay obvious.

Keep these items on the same first result card:
- preset label
- validation command
- first generated starter docs to open next

Example result-card stack:
- `Preset: web-app`
- `Validation: python3 -m unittest`
- `Open next: docs/landing-page-brief.md, docs/ui-ux-checklist.md`
