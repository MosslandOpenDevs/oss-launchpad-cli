# Preset web-app Playwright recovery note

When the first browser proof flakes, recover in the narrowest possible lane:

1. Re-run the same form input against the same result-card target.
2. Confirm the visible status copy before widening to downloads or secondary flows.
3. Keep the retry evidence attached to the same demo script or artifact path.
4. Only widen scope after the original form-to-card path is reproducible again.

This note keeps interactive browser checks aligned with a stability-first, failure-recovery workflow.
