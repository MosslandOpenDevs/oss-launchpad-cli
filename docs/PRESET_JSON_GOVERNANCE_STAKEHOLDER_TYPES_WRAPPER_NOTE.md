# Preset JSON governance stakeholder_types wrapper note

When the governance-sandbox scenario file arrives through a wrapper export, keep `stakeholder_types` in the same JSON/YAML bundle instead of asking the maintainer to flatten it by hand.

For the preset-facing phase-one handoff, keep the proof lane small:

- one scenario file,
- one primary action / result-card surface,
- one regenerated report bundle,
- one validation rerun before push.
