# Preset Web-App Result Card Download Check

Use this when the first visible `web-app` proof includes a downloadable artifact or handoff file.

## What to confirm
- The first form action still leads to one believable result card.
- The result card exposes exactly one clear download or handoff target.
- The demo script and README wording describe the same artifact.
- The visible proof stays narrow enough to review in one pass.

## Exit signal
Call the slice ready only when the result card, download target, and demo proof command all agree.
