# PRESET_WEB_APP_GOVERNANCE_REPORT_OUTPUT_DIR_NOTE

For the first governance-flavored `web-app` preset slice, keep the scope small and reviewable:

- one scenario-file input,
- one primary action,
- one result card,
- one visible exported report location.

If the generated governance bundle is surfaced as `report_output_dir`, treat it as the same report-location cue as `report_dir` or `reports_directory` so the first result card still points to a stable download/export target.

Validate the preset proof before commit/push.
