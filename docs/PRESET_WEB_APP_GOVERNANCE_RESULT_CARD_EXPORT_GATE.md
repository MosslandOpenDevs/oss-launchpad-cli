# Preset web-app governance result-card export gate

For the first governance-aligned web demo, keep the proof surface small and reviewable:

1. one scenario-aware input form,
2. one unmistakable primary action,
3. one result card that surfaces the report bundle/export path,
4. one validation rerun before commit/push.

This keeps the web-app preset aligned with UI/UX-first and Playwright-style replay discipline before the demo grows beyond the first card.
