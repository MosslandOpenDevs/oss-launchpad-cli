# Preset first maintainer update

Use this guide right after `init` when you want the first maintainer-facing progress update to sound concrete instead of generic.

## Mention three things

1. The preset that was generated
2. The first proof assets now present in the scaffold
3. The first command that demonstrates the scaffold is alive

## Copy-ready pattern

`Initialized the <preset> scaffold, confirmed the first proof files exist, and ran the preset validation command before the first public commit.`

## Preset cues

- `ai-agent` — mention `prompts/system.txt`, `evals/smoke_cases.jsonl`, and `docs/agent-demo-brief.md`
- `web-app` — mention `docs/landing-page-brief.md`, `docs/ui-ux-checklist.md`, and `docs/information-architecture.md`
- `python-lib` — mention `examples/basic_usage.py`, `tests/test_smoke.py`, and `docs/api-surface.md`
