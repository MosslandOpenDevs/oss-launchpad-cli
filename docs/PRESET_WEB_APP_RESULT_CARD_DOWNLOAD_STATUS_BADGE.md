# Preset web-app result card download status badge

Keep the first web-app result card honest: one primary action, one downloadable artifact, one unmistakable status badge.

## Review rule
- show whether the report artifact is ready before adding secondary controls
- keep the download label and status badge readable in the same scan path
- treat the first result card as complete only when the artifact state is obvious without clicking twice

## Good first-pass badge copy
- Report ready
- Report pending
- Report failed
