# PRESET_WEB_APP_FORM_TO_CARD_LOOP

Keep the first `web-app` proof narrow and reviewable.

## Goal
Turn one believable form input into one visible result card before adding extra screens.

## Minimum loop
1. Fill `docs/landing-page-brief.md` with one user goal and one primary action.
2. Keep `docs/information-architecture.md` aligned with that single path.
3. Use `docs/ui-ux-checklist.md` to verify the same happy path.
4. Re-run `sh demo/run_demo.sh` and review the visible result card proof.

## Scope rule
Do not claim a full product launch when only one form-to-result path is implemented.
