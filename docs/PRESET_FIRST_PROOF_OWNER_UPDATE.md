# Preset first-proof owner update

Use this note after scaffold generation when you want a short maintainer update that names the owner, proof pair, and next check.

## Template

`Owner <owner> is customizing <proof_asset> + <check_asset> for the first believable <preset> proof; next verification: <command>.`

## Keep it honest

- mention one visible proof asset
- mention one reproducible check asset
- keep the next verification command copy-ready
- do not imply launch readiness before the first manual proof passes
