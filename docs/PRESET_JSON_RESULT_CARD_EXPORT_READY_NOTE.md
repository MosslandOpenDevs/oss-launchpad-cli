# Preset JSON result-card export ready note

Use this note when the first preset picker already lands on one visible result card and you only need a quick export-readiness check.

Keep the proof narrow:

- one chosen preset,
- one visible result card,
- one explicit export or copy target,
- one visible validation command on the same card.

If the export target or validation command disappears, keep the flow in review mode instead of widening the demo.
