# Preset web-app result-card signoff note

Use this note when the first web-app proof already reaches one reviewable result card and you need a tiny release-facing signoff check.

- Keep the scope at one primary input form, one reviewable result card, and one visible download or handoff target.
- Confirm the status copy matches the actual proof shown on screen.
- Keep Playwright or browser-check recovery steps next to the signoff note before widening the flow.
