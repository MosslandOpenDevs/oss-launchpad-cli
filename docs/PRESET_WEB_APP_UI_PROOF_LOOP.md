# preset web-app UI proof loop

Use this note before widening the first web-app preset implementation beyond a single believable UI proof.

## Proof loop

1. Keep the first slice to one form or landing section.
2. Pair it with one result/check artifact that a reviewer can inspect quickly.
3. Re-run the same demo command before changing adjacent screens.
4. Only widen scope after the first form-to-proof loop is stable.
