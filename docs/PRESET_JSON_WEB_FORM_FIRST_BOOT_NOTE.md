# Preset JSON web-form first boot note

For the first web-app demo slice, start from the exported preset catalog instead of hand-copying labels.

Recommended proof order:

1. `oss-launchpad presets --preset web-app --json`
2. one form wired from that preset payload
3. one visible result card
4. one export/download target

Keep the first browser proof scoped to that single form -> card -> export loop.
