# PRESET_FIRST_PROOF_LABELS

Use these labels when you need a short, honest name for the first believable proof after scaffold generation.

## Label goals

A good first-proof label should:

- name one visible proof asset,
- imply one reproducible check asset,
- stay narrow enough for a day-zero commit or maintainer update,
- avoid overselling the scaffold as production-ready.

## Preset labels

### ai-agent

- `first agent brief + smoke cases`
- `prompt contract + eval smoke proof`
- `demo brief ready for first review`

### web-app

- `landing brief + ux checklist proof`
- `first landing-page proof pair`
- `day-zero web launch proof`

### python-lib

- `basic usage + smoke test proof`
- `first api surface proof pair`
- `library scaffold proof-of-life`

## Usage rule

Prefer labels that mention the proof pair already printed by `oss-launchpad init` rather than roadmap language.
