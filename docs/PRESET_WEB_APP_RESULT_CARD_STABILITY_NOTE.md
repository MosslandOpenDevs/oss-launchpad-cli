# PRESET_WEB_APP_RESULT_CARD_STABILITY_NOTE

Use this note when the first web-app proof already has one visible result card and the next question is whether to widen scope.

## Rule

Keep the first result card stable before adding alternate tabs, extra cards, or secondary actions.

## Stable means

- one deterministic input path
- one reviewable result card
- one reproducible smoke/demo command
- one obvious artifact or screenshot target
