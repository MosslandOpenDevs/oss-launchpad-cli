# First proof audit

Use this quick audit before the first public proof screenshot, demo clip, or launch note.

## Check three things

1. The starter asset named in the preset still exists.
2. The proof asset path in the generated scaffold still matches the README/launch docs.
3. The validation command still points at the smallest reproducible smoke check.

## Why this exists

The scaffold is only helpful if the first proof path stays obvious after day-zero edits.
