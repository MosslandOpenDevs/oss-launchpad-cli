# Preset first release signal

Use this note when the scaffold exists, tests pass, and you need a compact rule for deciding whether the first release proof is believable enough to show publicly.

## Release signal

A preset is ready for the first public release proof when all of the following are true:

- the preset-specific validation command passes,
- the release proof opens one user-visible asset and one reproducible proof asset,
- `docs/launch-scorecard.md` reflects the same proof pair,
- the README still points to the same preset-specific first proof path.

## One-line maintainer check

`First release signal: validation passes, proof pair is visible, launch-scorecard matches, README handoff stays aligned.`
