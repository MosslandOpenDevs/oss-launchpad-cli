# Preset first-proof scope status line

Use this note when the generated scaffold already has a believable proof pair, but you want one sentence that keeps the first public status update honest about scope.

## Template

`First proof is ready for <preset>, but keep the public status scoped to <proof pair> until <next missing check or customization> is done.`

## Examples

- `First proof is ready for ai-agent, but keep the public status scoped to docs/agent-demo-brief.md + evals/smoke_cases.jsonl until the real eval command is added.`
- `First proof is ready for web-app, but keep the public status scoped to docs/landing-page-brief.md + docs/information-architecture.md until the real app setup variables are filled in.`
- `First proof is ready for python-lib, but keep the public status scoped to examples/basic_usage.py + tests/test_smoke.py until the first exported API is finalized.`

## Quick review

Before posting, verify that the sentence names:

1. the preset,
2. the visible proof pair,
3. and the next missing change that prevents a broader readiness claim.
