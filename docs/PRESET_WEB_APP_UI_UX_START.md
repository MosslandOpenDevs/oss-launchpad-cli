# preset web-app ui/ux start

Use this note before widening the first `web-app` preset proof beyond one form and one result card.

Start with the smallest believable UI/UX slice:

1. one user action,
2. one visible result card,
3. one downloadable or reviewable proof artifact,
4. one reproducible validation command.

This keeps early web-app scaffold polish aligned with UI/UX-first scope control and replayable review evidence.
