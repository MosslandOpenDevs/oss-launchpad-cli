# Preset JSON Single-Preset Owner Note

Use `oss-launchpad presets --json --preset <name>` when the first browser demo, picker, or setup form should stay scoped to one preset, one visible owner, and one believable result card.

Keep the first slice small:
- request one preset payload
- show one primary owner-facing setup path
- end with one result card or one downloadable scaffold handoff

Widen to multi-preset browsing only after that single-preset flow is readable and reproducible.
