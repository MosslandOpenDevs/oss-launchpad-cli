# Preset first proof commit message

Use this note when the generated scaffold has been customized enough for the first believable manual commit.

## Commit message pattern

`Add first <preset> proof assets`

Examples:

- `Add first ai-agent proof assets`
- `Add first web-app proof assets`
- `Add first python-lib proof assets`

## What should be true first

- one visible proof file was customized,
- one reproducible proof file or command was updated,
- and `python3 -m unittest tests/test_cli.py` still passes in this repo.

## Why this matters

The first manual commit should sound like a proof-of-life checkpoint, not a vague scaffold touch-up.
