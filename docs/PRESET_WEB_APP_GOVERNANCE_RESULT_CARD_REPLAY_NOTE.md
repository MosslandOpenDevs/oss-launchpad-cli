# PRESET_WEB_APP_GOVERNANCE_RESULT_CARD_REPLAY_NOTE

Keep the first governance web-app slice small and reviewable:

1. one scenario-file-aware input,
2. one primary CTA,
3. one stable result card,
4. one visible export or download cue,
5. one validation rerun before commit/push.

Use UI/UX-first copy and Playwright-style replay discipline so the card can be rechecked step by step instead of hand-waved as a demo idea.
