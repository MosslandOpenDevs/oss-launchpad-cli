# PRESET_FIRST_REVIEW_SIGNAL

Use this note when the scaffold exists and you want to know whether the repo is ready for a real first review.

## Review-ready signals

1. The preset-specific proof files have meaningful placeholder content instead of untouched boilerplate only.
2. The printed smoke command still works after the first manual customization.
3. The launch plan explains audience, proof artifact, and first release scope in one pass.

## Suggested outcomes

- `review-ready` — scaffold plus first proof is believable enough for outside review.
- `customize-more` — preset files still read like untouched scaffolding.
- `rerun-smoke` — manual edits landed, but the printed validation path has not been rechecked yet.
