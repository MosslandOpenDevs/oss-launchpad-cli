# Preset first-proof push note

Use this note when the generated scaffold already has a believable first proof pair, but you want to keep the first public push modest and honest.

## Copy-ready note

```text
First public push: show one preset-specific proof asset plus one reproducible check asset, and keep the diff small enough to review in one pass.
```

## What counts as a proof pair

- `ai-agent`: a prompt or eval asset plus a smoke/eval command
- `web-app`: a landing/UI asset plus a visible review or setup check
- `python-lib`: an API/example asset plus a test or import smoke check

## Why this exists

The first public push should look alive and reviewable, not artificially complete.
