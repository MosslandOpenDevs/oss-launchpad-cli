# PRESET_WEB_APP_RESULT_CARD_ACCEPTANCE.md

Use this note when the first web-app preset proof needs a compact acceptance bar before adding more routes or screens.

## Acceptance bar

1. One primary form accepts the minimum starter input.
2. One reviewable result card renders the core output without secondary panels.
3. One obvious download, export, or handoff action stays visible from the same proof path.
4. One replay command or browser-proof note is recorded with the artifact.

## Why it exists

This keeps the first preset web-app slice aligned with stable UI proof, single-screen clarity, and reproducible Playwright-friendly review.
