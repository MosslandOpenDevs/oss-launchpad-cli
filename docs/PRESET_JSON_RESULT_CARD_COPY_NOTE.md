# Preset JSON Result Card Copy Note

Use this note when a preset-driven setup form already works and the next polish pass is only about the first result card's wording.

## Keep the first card scannable

Make the first result card answer four questions above the fold:

1. Which preset was selected?
2. What is that preset for?
3. Which proof asset should the maintainer open first?
4. Which reproducible command should they run next?

## Copy rule

Prefer:

- one short preset label,
- one sentence of proof-oriented value,
- one visible proof asset,
- and one obvious next command.

Avoid turning the first card into a roadmap dump.

## Minimal field stack

- Preset label
- Preset summary
- First proof file or doc
- Validation or smoke command

If those four fields stay readable together, the result card is good enough for the first preset-picker demo.
