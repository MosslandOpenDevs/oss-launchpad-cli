# Preset JSON result card export note

When wiring `oss-launchpad presets --json` into a small setup form, keep the first believable proof narrow:

1. one preset chooser,
2. one visible result card,
3. one explicit export or copy target.

The result card should keep the preset label, the validation command, and the export target visible together so the maintainer can move from selection to proof without guessing the next step.
