# Preset first proof bundle alias note

When a maintainer keeps both a human proof note and a machine-check artifact, prefer one shared proof bundle name.

Why it helps:

- the first public proof stays easy to reopen
- README proof language and validation evidence stay paired
- repeat review passes do not drift into ad-hoc filenames

Use this note when the first believable preset proof already has more than one artifact but should still read like one narrow reviewable slice.
