# Preset first JSON proof note

Use this note when the first believable proof needs one machine-readable artifact in addition to the generated scaffold.

## Rule

Keep the first JSON proof tiny and preset-scoped:

- `ai-agent`: one smoke eval case bundle
- `web-app`: one form/result payload sample
- `python-lib`: one import/output example payload

Pair that JSON artifact with one visible README or docs proof so the first public diff stays reviewable.
