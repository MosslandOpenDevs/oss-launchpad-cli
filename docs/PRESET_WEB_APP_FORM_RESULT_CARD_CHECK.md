# PRESET_WEB_APP_FORM_RESULT_CARD_CHECK

Use this before the first public web-app demo when the product is still proving one clear form-to-result loop.

## Check
- One primary form path should lead to one visible result card.
- The result card should show the main outcome before any secondary controls.
- The same demo command should still surface the proof artifact or landing brief used in review.
- If the UI adds extra panels, confirm they do not obscure the first result card on the initial viewport.

## Exit
If a reviewer can describe the form input, the submit action, and the first result card in one sentence, the proof is still scoped well enough.
