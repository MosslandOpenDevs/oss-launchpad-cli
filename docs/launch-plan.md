# Launch plan

Use this starter file to capture the first public-release intent for a generated repository.

## Core questions

- Who is the project for?
- What proof should a first visitor see in the first minute?
- What is intentionally out of scope for launch?
- Which review command should the maintainer rerun before publishing?

## Minimum launch checklist

1. Confirm the README explains the first successful run.
2. Link one demo or proof artifact.
3. Record the review command used before release.
4. Note the smallest public feedback loop after launch.
