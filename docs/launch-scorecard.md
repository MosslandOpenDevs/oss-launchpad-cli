# Launch scorecard

Use this scorecard after generating a starter repo and before making it public.

## Quick score

- README clarity: pass / needs work
- Demo proof: pass / needs work
- Contribution path: pass / needs work
- Release notes path: pass / needs work
- Review command documented: pass / needs work

## Reviewer note

A repo is launch-ready when a new visitor can understand the project, run the proof flow, and find the contribution path without maintainer hand-holding.
