# Preset first proof owner-ready check

Use this note after the generated scaffold passes its smoke command and you want a compact owner-facing check before the first public proof update.

## 30-second review

1. Confirm one visible proof asset exists for the selected preset.
2. Confirm one reproducible check asset still matches that proof.
3. Keep the first proof claim narrow: day-zero proof, not full project maturity.
4. End with the exact next maintainer action.

## Copy-ready owner update

`First preset proof is owner-ready for <preset>: one visible proof asset plus one reproducible check asset are in place, scope stays day-zero, next action is <action>.`

## Hold instead of post when

- the proof asset exists but the matching check asset is missing,
- the smoke command has not been rerun,
- the message sounds release-ready instead of first-proof-ready,
- or the next maintainer action is still generic.
