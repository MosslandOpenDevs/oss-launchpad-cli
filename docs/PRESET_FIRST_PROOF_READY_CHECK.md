# Preset first proof ready check

Use this checklist after scaffold generation or the first preset-specific manual edit.

A preset's first proof is ready to show when all of the following are true:

1. one visible proof asset exists for the chosen preset,
2. one reproducible check asset exists next to it,
3. the README or launch-plan explains why that proof matters,
4. the printed validation or review command still matches the generated files.

If any item is missing, keep the repo in scaffold mode and avoid claiming that the preset already feels launch-ready.

## Compact status line

- **Ready:** the preset has one believable proof asset, one reproducible check, and matching README/launch-plan guidance.
- **Not ready:** the scaffold exists, but proof assets or verification guidance still need one more concrete pass.
