# preset json form result-card review note

Use this note when the preset JSON setup form already renders one believable result card and the next maintainer pass is a tight review loop instead of a wider redesign.

## Keep visible

- the selected preset,
- the validation command,
- and the one review target on the result card.

## Template

`Review the <preset> result card with <validation command> first, then adjust <single review target> before widening the flow.`

## Example

`Review the web-app result card with npm run lint first, then adjust the primary download cue before widening the flow.`
