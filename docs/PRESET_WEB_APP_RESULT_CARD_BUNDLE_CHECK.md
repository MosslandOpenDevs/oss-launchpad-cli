# PRESET_WEB_APP_RESULT_CARD_BUNDLE_CHECK

Keep the first `web-app` preset proof narrow:

1. one primary form
2. one visible result card
3. one artifact bundle a reviewer can download or inspect

Why this exists:
- it matches a stability-first UI slice
- it keeps demo scope reviewable
- it avoids widening into multi-screen polish before the first proof is solid
