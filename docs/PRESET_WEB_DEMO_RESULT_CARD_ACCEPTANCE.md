# preset web demo result-card acceptance

Use this note when the first web-app demo should stay scoped to one form submission plus one visible result card.

## Acceptance lane
- Keep one primary form path.
- Render one reviewable result card.
- Keep one report/download affordance attached to that card.
- Validate the same path with the demo script before widening the UI.

## Why it matters
This keeps the first UI proof small, reviewable, and reproducible.
