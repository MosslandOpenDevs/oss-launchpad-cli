# Preset JSON Governance Sandbox Result Card Lane

Use the preset JSON starter to shape a governance-sandbox web demo around one credible slice:

- one form that imports or pastes a scenario payload,
- one primary action that runs the rehearsal,
- one result card that shows the headline outcome before wider navigation.

Keep the layout intro-first, keep the result card reviewable, and keep Playwright proof scoped to that single form-to-card loop before widening the UI.
