# Preset Web App Result Card Download Gate

Use this note when the first preset web app demo can render a result card, but you still need to decide whether the download path is believable enough to mention in README or release updates.

## Gate

- The form reaches one stable result card without manual recovery.
- The primary card fields match the generated preset summary.
- One explicit download action exposes the expected report or JSON artifact.
- The saved filename or bundle path is reviewable without guessing hidden state.

Only after those checks pass should the result card be described as download-ready.
