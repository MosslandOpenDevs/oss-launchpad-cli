# Preset first owner note

Use this note when a generated scaffold is valid but still needs a human owner to take the first real step.

## Include

- chosen preset
- generated proof files
- first smoke command
- first customization file
- owner question

## Template

`Scaffold ready for <preset>. Proof assets are in <paths>. Run <command> first, then edit <file>. Owner decision needed: <question>.`
